# AI-for-Beginners

Learning materials for the **AI for Beginners** sessions (Cohort 3).

After each session, I'll share that session's materials here, so this repository will grow as the session goes on.

## Materials


| Session | Topic                              | Files                                                                       |
| ------- | ---------------------------------- | --------------------------------------------------------------------------- |
| 1       | What is AI? and Understanding data | [Interactive HTML](AI_Basics_Session1.html) · [PDF](AI_Basics_Session1.pdf) |


The HTML files are interactive: download one and open it in any web browser (Chrome, Edge, Firefox) to use the demos and quizzes. The PDF is a printable version of the same content.

## How to keep up to date

- **Star** this repository (the ⭐ button at the top right) so you can find it again easily.
- **Fork** it if you want your own copy to keep notes in.
- **Clone** it and run `git pull` after each session to get the newest materials:
  ```bash
  git clone https://github.com/arifanony/AI-for-Beginners.git
  cd AI-for-Beginners
  git pull
  ```
- Or simply click **Code → Download ZIP** on GitHub if you don't use Git.
